# strike-kinematics

Turns DeepLabCut pose output (.csv or .h5, native 3-level scorer/bodypart/coords header) plus calibration (fps, pixels per meter, mass in kg) into per-frame, per-bodypart kinematics: time_s, x_m, y_m, speed_mps, accel_mps2, force_N. Low-likelihood points are dropped, short gaps are linearly filled, and positions are smoothed and differentiated with a Savitzky-Golay filter (window 11, order 3). Run `pip install -r requirements.txt`, then `python make_sample_data.py` and `python run.py data/sample_strike.h5 --fps 50000 --pixels-per-meter 20000 --mass-kg 1e-5`, which writes outputs/kinematics.csv and prints peak speed, acceleration and force; `pytest` runs the tests. This is a reconstruction of a kinematics pipeline I built for the Patek Biomechanics Lab (Oct 2025 to May 2026); the original lived on a lab account I no longer have access to.
